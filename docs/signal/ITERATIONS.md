# Итерации до полного клиента

Цель: стабильный, быстрый, приватный и безопасный клиент Signal с функциями настольного и мобильного Signal (кроме невозможного на платформе: FCM, Google Pay), регистрацией по номеру, без кода Telegram API и Telegram-функций, с Tauri-версией для macOS, Windows и Linux и собственной темой в стиле Signal.

Каждая итерация: запуск субагентов → ожидание → проверка (tsc, ESLint, CSS, браузер, живой тестовый аккаунт) → исправления → план следующей → запуск. После каждого слияния изменения пушатся в рабочую ветку и `master`.

## 1. Основа (идёт)
- Вычищение сетевых обращений к Telegram, CSP только на свой origin и туннель.
- Перенос истории при привязке (link-and-sync).
- HTTP/2 для storage, групп и CDN; исправление приёма и записи больших объёмов в TLS-клиенте WASM.
- Этап 1: удаление функций Telegram (платные функции, проверки Premium, перевод, AI, викторины, теги, chatlists, custom emoji, Instant View, карты, облачный пароль, модалки, каналы, форумы, боты, Mini Apps).
- Интерфейс: эмодзи в реакциях, плашки удалённых сообщений, галочки доставки и прочтения, цвета аватаров, свой профиль.

- Tauri: транспорт через команды и IPC-каналы на библиотеке туннеля, трей и системные уведомления, новое имя и иконки, обновления с наших релизов, сборки для macOS, Windows и Linux в CI.

## 3. Группы и синхронизация
- Управление группами v2: создание, название, описание, аватар, участники, админы, права, ссылки-приглашения с одобрением, заявки, баны, выход и завершение группы.
- Запись в storage service: архив, закрепы, mute, «непрочитанное», контакты, блокировки, настройки, папки.
- Синхронизация `deleteForMe`, запросы на переписку (принять, удалить, заблокировать, спам), блокировка.

## 4. Регистрация и основное устройство
- Регистрация по номеру: verification session, captcha, SMS и голосовой код, атрибуты аккаунта, ключи, профиль.
- PIN и SVR2/SVR3 (attestation: патч `attest` для WASM), registration lock, смена номера.
- Поиск по номеру через CDSI (attestation).
- Привязка других устройств к основному, управление связанными устройствами.

## 5. Медиа и контент
- Истории: просмотр, отправка медиа и текста, My Story, списки рассылки, групповые истории, ответы, реакции, просмотры.
- Стикерпаки: установка, отправка, синхронизация; превью ссылок через contentproxy; отправка контактов; интерфейс опросов и закрепов; альбомы из нескольких вложений.

## 6. Профиль и приватность
- Редактирование профиля и аватара, юзернейм (создание, смена, ссылка, QR), видимость и поиск по номеру.
- Safety numbers, key transparency, проверка ключей, настройки приватности, исчезающие сообщения по умолчанию.

## 7. Звонки
- 1:1 и групповые звонки, call links: в Tauri через нативный стек RingRTC, в браузере после отдельного исследования медиастека (`docs/signal/CALLS_RESEARCH.md`).

## 8. Внешний вид
- Тема в стиле Signal (светлая и тёмная), цвета чатов и обои Signal, профили уведомлений, доступность, локализация EN/RU.

## 9. Резервные копии и остальное
- Secure backups, attachment backfill, платежи MobileCoin (показ и отправка, если возможно на платформе), бейджи.

## 10. Надёжность
- Аудит безопасности, фаззинг парсеров, шифрование локальной базы код-паролем, профилирование скорости, консоль без ошибок, сквозные тесты на живом тестовом аккаунте, документация развёртывания.

## 11. Второй клиент на Telegram Web K (идёт)
- Telegram Web K (`morethanwords/tweb`, GPL-3.0-only) лежит в `webk/`; коммит, исключённые файлы, лицензия и локальные изменения — в `webk/NOTICE.md`. GPL-3.0-only совместима с GPL-3.0-or-later остального репозитория и с AGPL-3.0 libsignal (раздел 13 GPL-3.0).
- Туннель `proxy/` общий для обоих клиентов.
- Движок не скопирован: Web K в своём воркере (`SharedWorker`) запускает тот же провайдер Web A `src/api/signal` над движком `src/lib/signal` (псевдоним `@signal-app/provider`). Менеджеры Web K не говорят с Telegram: `ApiManager.invokeApi` передаёт методы `appSignalManager` (`webk/src/lib/appManagers/appSignalManager.ts`), который отвечает данными провайдера в форме Telegram (`webk/src/lib/signal/builders.ts`) и превращает обновления провайдера в обновления Telegram. Сеть MTProto (`networker`, транспорты, DC) больше не вызывается.
- Сборка: один origin. `npm run dev` поднимает оба Vite-сервера на одном порту (`/a/` — Web A, `/k/` проксируется на сервер Web K). `npm run build:production` (`dev/build.ts`) собирает Web A в `dist/a`, Web K в `dist/k` и корневую страницу, которая открывает фронтенд по умолчанию; его задаёт одна константа `DEFAULT_FRONTEND_PATH` в `plugins/frontends.ts` (сейчас `a/`, пока Web K не полон; цель — `k/`), ей следуют nginx, Tauri и dev-сервер. Tauri стартует с корневой страницы и пускает в IPC обе. Переключатель: «Switch to A version» в меню Web K, «Switch to K version» в меню «More» Web A; смена URL работает так же.
- Хранение одно: аккаунт, ключи, сообщения, вложения и настройки Signal — в хранилищах движка, имена по `getEngineStoreName`; метка слота аккаунта (`account1` с `isLinked`, `userId` в id Web A) общая. Web K сдвигает id пиров на `1e10`, чтобы они не совпадали с его папками и служебными id, и переводит их обратно на границе.
- Один движок на слот: `startClient` берёт Web Lock (`src/lib/signal/engineOwnership.ts`) и забирает его у движка, который его держит, — тот останавливается. Вкладка другого фронтенда показывает экран «неактивно» (общий канал `tgweb`), по клику забирает движок обратно.
- Тема Web K: синий Signal (`#2c6bed`) и однотонный фон без узора Telegram в светлой и тёмной темах, QR-код без логотипа в центре, нейтральные иконки и логотип (облачко), строки интерфейса называют TeleSignal.
- `npm run check:hosts` проверяет исходники Web A и собранный бандл Web K; ссылки Telegram-функций, которые Web K ещё строит, ведут на зарезервированные имена `.invalid`.
- Сообщения (Web K): реакции (показ с авторами, добавление, смена и снятие, список тех, кто отреагировал), ответы с цитатой и переход к исходному сообщению, правка (сутки, «изменено»), удаление у себя и у всех (сутки, только свои сообщения, у собеседника только «у себя»), пересылка (одна копия: каждая получает свой `random_id` до сохранения в движке), поиск по тексту в чате и по всем чатам с подкачкой страниц, счётчиком совпадений и фильтром по отправителю, поиск пользователя по имени кнопкой «Find by username» (сервер спрашивают по нажатию и только для имени Signal вида `nickname.NN`), меню без пунктов Telegram, форматирование в поле ввода без подчёркивания, цитат и ссылок. Черновики хранятся в памяти вкладки и не синхронизируются.
- Закреплённые сообщения в обоих клиентах: движок отправляет `pinMessage`/`unpinMessage` (Signal Desktop `sendPinMessage`), хранит три последних закрепа, принимает закрепы только от тех, кто может менять группу (и в группах «только администраторы пишут», как Signal Desktop), добавляет в ленту уведомление «закрепил сообщение» при отправке и получении, снимает истёкшие закрепы по таймеру; провайдер отвечает на `fetchPinnedMessages`, `pinMessage`, `unpinAllMessages` и шлёт `updatePinnedIds`. Web K: пункты Pin/Unpin, закреплённая полоса, снятие всех; Web A: диалог без «только у меня». В демо отправка не проходит (нет сервера) и закреп откатывается; полоса проверена на закрепах, записанных в базу.
- Информация о сообщении в Web K: пункт Info у исходящих, получатели по статусам (не отправлено, просмотрено, прочитано, доставлено, отправлено, ожидает) из `fetchMessageSendDetails`.
- Упоминания: автодополнение участников группы работает; Web K отправлял упоминание как текст (`inputMessageEntityMentionName` с input user), теперь это упоминание Signal по ACI. Набор текста в обе стороны уже есть в адаптере (`messages.setTyping`, `updateChatTypingStatus`); на демо без второго участника не проверен.
- Реакция любым эмодзи: кнопка «ещё» у полосы реакций открывает обычную панель эмодзи с поиском.
- Общие медиа в обоих клиентах: поиск по типам `media`, `documents`, `links`, `audio`, `voice` (view once не попадает); вкладки профиля Web A теперь видны и у пользователей, Web K получает счётчики вкладок из `fetchSharedMediaCounts`. Ссылки и медиа проверены на демо (в Web K сами фото пока «Unsupported Message» до порта медиа).
- Работает на демо-аккаунте и через туннель: экран привязки с настоящим кодом `sgnl://linkdevice`, список чатов (закрепление, непрочитанные, mute, галочки), открытие личного и группового чата с историей, отправка текста (неудачная отправка помечается), уведомления Signal (звонки, изменения группы, номер безопасности), статус соединения, переход между `/k/` и `/a/` с теми же чатами.
- Список чатов: архив и папка «Archived Chats», закрепление, mute и unmute, пометка прочитанным и непрочитанным, удаление чата, блокировка и разблокировка (`messages.toggleDialogPin`, `folders.editPeerFolders`, `account.updateNotifySettings`, `messages.markDialogUnread`, `messages.deleteHistory`, `contacts.block`/`unblock`). Папок чатов нет, как и у Web A для Signal; «Clear history», «Chat Folders» и очистка по датам в календаре чата убраны: Signal не удаляет часть чата, и адаптер отклоняет `messages.deleteHistory` с `just_clear` или датами, а не удаляет весь чат. Предел закреплённых чатов Signal (четыре) показывается одним сообщением Signal вместо окна Telegram Premium. Mute — на срок или навсегда; кнопки звука чата нет: Signal хранит только mute.
- Группы: участники с ролями (администратор, метки участников), описание и ссылка в профиле группы, создание группы (`messages.createChat`), изменения группы через провайдер (название до 32 и описание до 480 графем — их проверяет провайдер при сохранении, аватар до 3 МиБ — предел загрузки сервера групп, участники, администраторы, права, заявки, выход, таймер исчезающих сообщений). Провайдер отвечает `undefined` только вместе с сообщением об ошибке (и для удаления чата и таймера личного чата); отказ отклоняет запрос Web K, а причину (например, «The group could not be updated…», длинное название, последний администратор) Web K показывает одним сообщением. Ссылка группы — экран «Group Link» как в Signal: включить и выключить, QR-код, копировать и поделиться, сбросить, одобрение новых участников администратором (`messages.exportChatInvite`, `deleteExportedChatInvite` выключает ссылку через новый метод провайдера `disableChatInvite`, `editExportedChatInvite`); выключенная ссылка показывается выключенной. Заявки на вступление приходят в полный чат (`requests_pending`, `recent_requesters`) для полосы и списка заявок. Строка «Reactions» убрана из редактора группы: Signal принимает любые реакции. Без сервера Signal изменения не проходят; проверено до этого вызова.
- Личный профиль: имя, о себе, телефон, группы в общих, номер безопасности (попап с QR-кодом, который сканирует телефон собеседника, 60 цифрами и отметкой «проверено»; сама отметка не проверена в браузере, чтобы не менять демо-аккаунт). Пункт «Add Contact» и «Send a Gift» убраны.
- Запросы сообщений: полоса с ответами, как у Web A: «Accept», «Delete», «Block» и у личного чата «Report spam» (с флажком «Also block this person»); крестик только прячет полосу в этой вкладке и запрос не принимает. Принять, удалить, заблокировать и пожаловаться — ответы провайдера (`messages.hidePeerSettingsBar`, `deleteHistory`, `contacts.block`, `messages.reportSpam`); неудачный ответ оставляет полосу и показывает ошибку. Список заблокированных с подкачкой (`contacts.getBlocked`).
- Исчезающие сообщения: таймер личного чата задаётся, уведомление «You set messages to auto-delete» появляется в ленте и в строке списка чатов.
- Новый чат: контакты, поиск по имени и username. Меню «+» без «New Channel» и «New Group Call»; пункт «Money» в главном меню убран.
- Медиа (Web K): фото, альбомы (как платные медиа Telegram без цены), видео, GIF, голосовые с волной, аудио, файлы, стикеры, превью ссылок и контакты в ленте; просмотрщик с загрузкой, масштабом и пересылкой (альбом тоже скачивается); вкладки общих медиа в профиле (медиа, файлы, ссылки, музыка, голосовые) со счётчиками (`sharedMedia.ts`); отправка фото и видео со сжатием Web K и подписью, файлов, голосовых (запись работает после переноса ворклета в файл и возврата воркеров `opus-recorder`), стикеров; лимит вложения 100 MiB, как у Signal Android. Убраны: пункты меню вложений Telegram (статья, коллаж, музыка, геопозиция, деньги, опрос, чек-лист), спойлеры медиа, вкладка GIF (поиск GIF у Signal идёт к третьей стороне), расшифровка голосовых, запись кругляшей, редактор, заменяющий медиа при правке. Проверено на демо-аккаунте (`signalDev.seedDemo()` теперь ждёт старта движка и генерирует голосовое, аудио, PDF, видео и GIF в коде); отправка в демо помечается неудачной, так как сервера нет.
